# 腾讯云账号注册与准备指南（参加 38 元秒杀活动用）

> 目标：注册全新腾讯云账号 → 实名认证 → 人脸核身 → 准备扫码登录。全程约 15 分钟。

**⚠️ 先确认资格**：这是"新用户专享"活动，**必须是从未在腾讯云买过任何付费产品的新账号**（比如没买过任何服务器/流量包/域名等付费产品），每个身份证限购 1 台。如果这个身份证以前买过腾讯云的东西，这个活动就参加不了，别白忙。

---

## 准备材料
- 本人身份证
- 本人实名的微信（登录扫码、人脸核身都靠它）
- 手机号（收验证码）

---

## 第一步：注册账号（约 2 分钟）

1. 打开：**https://cloud.tencent.com/register**
2. 选择 **微信扫码注册**（最方便，后面抢购登录也用它）
3. 手机微信扫一扫 → 手机上确认授权
4. 按提示绑定手机号、设置密码
5. 注册完成

> 如果提示手机号/微信已注册过腾讯云：说明你之前有过账号。可以直接用那个账号（前提是符合"新用户"要求），或换一个没注册过的手机号/微信。

## 第二步：实名认证（约 5 分钟，必做）

1. 登录腾讯云后，点右上角**头像 → 实名认证**
   （或直接打开 https://console.cloud.tencent.com/developer 找到"实名认证"）
2. 选择 **个人认证**
3. 填写**本人的姓名 + 身份证号**
4. 按提示完成验证
5. 页面显示"已实名认证"即可

> 一个身份证只能实名一个腾讯云账号。如果你的身份证已经实名过别的腾讯云账号，就不能再实名新号。

## 第三步：人脸核身（约 3 分钟，活动专用）

1. 打开：**https://cloud.tencent.com/act/pro/face_authentication**
2. 用微信扫页面上的二维码
3. 手机上按提示完成人脸识别（眨眼、张嘴等动作）
4. 显示**已通过**即可

> 失败就换个光线好的地方、摘掉口罩重试；连续失败隔几分钟再来。

## 第四步：准备就绪 → 扫码登录

做完前三步后，告诉对方"已就绪"。接下来只需 1 分钟：

1. 到对方电脑前（或远程协助）
2. 对方会弹出一个腾讯云登录窗口
3. 点窗口**右上角【登录】** → 用你的**微信扫一扫** → 手机确认
4. 看到"登录成功"就完事了

之后抢购全自动运行，你不用再操作；抢到后会在 1 小时内通知你去付款（用你的账号登录腾讯云控制台付款即可，支持微信/支付宝）。

---

## 常见问题

| 问题 | 处理 |
|---|---|
| 注册提示账号已存在 | 换没注册过的方式，或用旧账号（需符合新用户要求） |
| 实名提示身份证已被占用 | 一个身份证只能实名一个腾讯云账号，无法再实名新号 |
| 人脸核身一直失败 | 光线充足、摘口罩、正对镜头；隔几分钟重试 |
| 不确定算不算"新用户" | 不用自己判断——扫码登录后对方会用官方接口帮你验证，全绿才算通过 |
| 要付钱吗？ | 注册/实名/人脸都免费；抢到服务器才需付款 38 元（1 小时内） |
